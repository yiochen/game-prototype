The user-approved Shop is integrated in native Godot. The [contract](contract.md) and [verification](verification.json) record Edit-only entry, shared maple/beige popup, bag return, 1.1-second flights, persistent stock/inventory and migration. Gameplay and `--shop-gallery` use the same production controls.

Validation includes 34 new domain checks, 306 passing native touch/UI checks across 320×720, 390×844, 720×1560, 1080×2340, 1440×1000 and 844×390, 38 editor regressions and 146 general app checks. Existing hiring (33), chef UI (27), navigation (35) and other rule regressions also passed. Captures show normal/pressed/disabled/sold-out, actual flights, bag return and Shared presentation. The observed renderer is Mobile/Metal on Apple M4. No Android device was connected, so there is no claim of an on-device install or actual Android Vulkan verification.

Known pre-existing failures are retained in evidence: the repository's two absent refinement-artifact cases; one old backdrop fixture each in session/customer tests; and the sprite picker's old dish-attachment fixture errors. The native failures were reproduced using unchanged HEAD scripts in fresh isolated test data. The unchanged packaging unit harness also omits newer recipe/staff manifests in its synthetic fixtures, causing those tests to fail before their intended boundary. Actual runtime preflight, production asset/provenance gates, signing verification, source hashing and full APK audit passed. No production gate was bypassed to accommodate those fixtures.

Native tests used a disposable copied runtime and `SushiLoopTicketsTest-*` save identities, never the user's normal data. Image-import caches were reused only for source-identical resources; the real importer, all asset validation and normal export/audit still ran. All 479 runtime source files match the final build. The APK is a nondebuggable release, code 71, with the original pinned signer, package and save identity. The initial desktop pixel cap was caught by high-density phone checks and corrected before final delivery; six final GPU runs pass.
