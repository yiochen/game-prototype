# Full-tile decoration study review

The user requested a small modified-object experiment on the wireframe site. Five underwater families are modeled as full-cell compositions above a separate bed at the selected 70% height projection. The new review route is #decoration-study, also linked from both full scene pages.

The native audit passes all 21 captures. Top-down mesh-union coverage excluding the separate floor: low rocks 93.9%, coral 92.3%, kelp 88.3%, cobalt peaks 95.1%, column 92.5%. All native X/Y bounds fit the cell. Captures retain a fixed registered camera and transparent frame.

The first visual pass exposed a uniform platform and overly regimented coral. Revision 2 replaced that platform with overlapping stones and gave kelp actual volume. Revision 3 simplifies the kelp facet materials so individual leaves read as coherent forms. Superseded native stills and recipes remain in iterations/.

MCP views were inspected from top, front/right and three-quarter angles. Final phone screenshots were inspected for density, mixed heights, natural gaps, and repetition. The selected study deliberately offers a repeated-single-object patch to expose repeating motifs instead of hiding them. Current notes: this is a geometry study with only five primary shapes; it is not final scene art, lighting or an assertion that all repetition is eliminated.

164 engine tests pass; production build passes. Three responsive browser tests pass at 390×844, 844×390 and 1440×1200. They check separate layer toggles, arrangement switching, facing controls, mixed/repeated patches, native image decoding and one document scrollbar. Initial browser tests found transparent SVG image margins intercepting controls; fixed by clipping each ample review viewport and disabling pointer events on the noninteractive SVG. Native sprite pixels remain unchanged and unclipped within those viewports.

Final scene asset approval is still pending. This experiment does not authorize the full asset update or close issue 33.
