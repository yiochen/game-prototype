# Expedition start-screen information options

Built-in image generation edits using [the expedition scene reference](./03b-two-width-strip.png). Pending UI interview Question 13. The accepted sequence is dock tap → expedition start screen → Start → active travel. Both options hide reward/creature previews. Sample equipment levels and back navigation are illustrative.
