# Harpoon placement UI options

Generated using the built-in image generation tool. These are proposals for UI interview Question 1, not accepted screens. The doodle direction remains the style baseline.

## Option A: anchored lower-right

```text
Use case: ui-mockup.
Asset type: polished commercial mobile game screenshot, portrait 9:16, edge-to-edge playfield, no phone frame, no presentation board.
Create a finished 2D doodle game UI for a submarine expedition. Confident slightly irregular dark ink outlines, rounded modular sprites, flat color fills, restrained paper grain, carefully drawn sticker icons, consistent line weight, crisp polished typography, no painterly concept art, no 3D. Deep navy and teal ocean, warm yellow submarine, ivory UI surfaces and coral accents.
Top-down view of a submarine traveling UP the screen over an ocean-bed canyon. Yellow submarine centered horizontally at 70% screen height, upward-facing nose and cone headlight. Cute teal spotted eel above it at 40% screen height, horizontally crossing the route, awaiting a first harpoon shot. No cable, no fired harpoon, no secondary weapon. Clear navigable central water with sparse reef silhouettes along both sides, small gear-shaped salvage pickups. Keep all upcoming danger ahead of submarine clearly readable. No portals, no powerup buttons, no extra ability slots.
Provisional compact HUD: top left a small ivory rounded hull badge with hull icon and three filled segments; top right gear-shaped salvage icon with exact number "72" plus separate small pause icon. Beneath the top row a narrow boss bar labeled exactly "SPOTTED EEL", full turquoise resistance fill and dark outline. No timers, depth number, earning rate, recipes, cash, level badges, instructional text, joystick or footer. The bottom stays underwater scenery.
One contextual harpoon action button only: round ivory sticker, dark ink outline, unmistakable upward-pointing harpoon icon, no word label. Large readable thumb-sized tap target, subtly raised ink shadow, no finger illustration. Button is an overlay on the continuous scene.
Option A layout: position harpoon button anchored to lower RIGHT edge at 85% screen height, comfortably inset from both screen edges, wholly separate from submarine and its headlight. Radius about 7% of screen width. This is the only bottom UI element.
```
