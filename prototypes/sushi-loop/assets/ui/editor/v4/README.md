# Reimagined restaurant editor — two UI directions

Status: **B approved for production** on 2026-10-19. The user selected [B — Indigo noren & warm ceramic](raw/b-indigo-ceramic.png) and authorized creative composition changes beyond the old layout. A remains a historical comparison.

The user rejected the v3 surface reskin as insufficiently professional and explicitly asked for creativity beyond the current game layout. These concepts therefore rethink the room staging, navigation grouping, contextual tools and inventory drawer together. They retain editing, currency, Shop, Live, inventory categories, placement, rotation and return semantics. The approved B uses horizontal categories and a three-visible-item Layout drawer with paging, superseding the previous right-side stack and two-item layout requirement.

| Direction | Complete screen | Character |
| --- | --- | --- |
| A — Cedar & paper | [Open concept](raw/a-cedar-paper.png) | Warm wood counter, light menu paper, jade primary action, welcoming workshop feel. |
| B — Indigo noren & warm ceramic | [Open concept](raw/b-indigo-ceramic.png) | Indigo cloth category rail, cream ceramic content, restrained vermilion accent, stronger sushi-house identity. |

Both use one prominent Live action, a quieter Shop, grouped Rotate/Return tools attached to selection, a clear placement footprint, and one complete editing drawer with coordinated passive surfaces. Return means storage rather than deletion; the inventory preview is one conveyor module rather than an entire route. The final B stock seals use neutral ivory/indigo so they do not compete with Live.

Only the approved restaurant world concept was supplied as an image reference. The previous editor screenshot was deliberately omitted. These are illustrative world compositions and UI directions; their generated scene projection, props and characters do not replace the approved registered native sprites or camera contracts.

[generation.json](generation.json) preserves exact prompts, reference roles and hashes, generated source paths, unchanged full outputs and dimensions. Initial and final images are in raw/. Production will keep text and counts dynamic, calibrate responsive geometry, and verify the chosen composition in Godot Android against the approved B direction. The coordinated production family is retained in [v5](../v5/); all future UI tickets extend B with the restaurant catalog and world references. Preserve action, pause, save and recovery behavior.
